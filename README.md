# WEB103 Prework - Creatorverse

Submitted by: **Fahreen Fairooz**

About this web app: **Creatorverse is an app built using React and Supabase to showcase content creators. Users can view creators, open each creator's page for more details, visit their channel, add new favorite creators, edit existing creators, and delete creators as well.**

Time spent: **8** hours

## Required Features

The following **required** functionality is completed:

- [x] **A logical component structure in React is used to create the frontend of the app**
- [x] **At least five content creators are displayed on the homepage of the app**
- [x] **Each content creator item includes their name, a link to their channel/page, and a short description of their content**
- [x] **API calls use the async/await design pattern via Axios or fetch()**
- [x] **Clicking on a content creator item takes the user to their details page, which includes their name, url, and description**
- [x] **Each content creator has their own unique URL**
- [x] **The user can edit a content creator to change their name, url, or description**
- [x] **The user can delete a content creator**
- [x] **The user can add a new content creator by entering a name, url, or description and then it is displayed on the homepage**

## Optional Features

The following **optional** features are implemented:

- [x] Picocss is used to style HTML elements
- [x] The content creator items are displayed in a creative format, like cards instead of a list
- [x] An image of each content creator is shown on their content creator card

## Additional Features

The following **additional** features are implemented:

- [x] Space-inspired landing hero with navigation buttons
- [x] Edit links are available from both cards and detail pages
- [x] Delete action includes a confirmation prompt
